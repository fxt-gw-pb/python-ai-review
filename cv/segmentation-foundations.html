分割基础：标签、损失与 IoU 指标

🧩 图像分割

分割任务：从一张标签到一张标签图

分类通常为整张图输出一个类别；目标检测为物体输出位置框；图像分割继续回答“哪些像素属于它”。同样一张包含三个人的照片，语义分割把三个人都标为“人”，实例分割需要三张独立的人体掩码，全景分割还要把道路、天空等区域纳入统一结果。选择任务时先写清输出，再决定模型，否则即使训练成功，也可能学到错误目标。

语义分割标签常是形状为 $H\times W$ 的整数矩阵，数值表示类别编号。实例分割通常是 $N\times H\times W$ 的二值掩码，加上长度为 $N$ 的类别数组；这里 $N$ 是当前图片的实例数量，不是类别总数。全景分割同时携带类别和实例身份。每个像素必须遵守事先确定的标签定义。颜色只是显示标签的调色板，红色像素并不意味着网络要回归 RGB 值。

张量与损失必须成套理解

任务 模型输出 标签 常用损失
二值前景分割 [B,1,H,W] logits 同形状，浮点 0/1 BCEWithLogitsLoss
互斥多类分割 [B,C,H,W] logits [B,H,W] 整数 CrossEntropyLoss
每像素多标签 [B,C,H,W] logits 同形状，独立 0/1 BCEWithLogitsLoss

logit 是还没有归一化的分数。二分类概率 $p=\sigma(z)=1/(1+e^{-z})$，概率阈值 $0.5$ 等价于 logit 阈值 $0$。互斥多类用 softmax 在类别维比较，预测时直接 argmax(dim=1) 即可。不能把已经 sigmoid 的值再次作为 logit，也不能对单通道输出做类别 argmax：只有一个通道时得到的索引永远是零。

逐像素交叉熵为

$$L_{CE}=-\frac{1}{|V|}\sum_{i\in V}\log p_{i,y_i},$$

其中 $V$ 是有效像素集合。未标注像素应从损失和评估同时排除，不能偷偷当作背景。当前景很小时，仅靠数量庞大的易分类背景就能使平均损失很低。Focal Loss 乘上 $(1-p_t)^\gamma$，降低容易样本的贡献；Dice Loss 则直接比较区域重叠。它们解决的问题相关，却不是“哪个更高级就用哪个”。

IoU、Dice 与像素准确率

设预测区域为 $P$，真值为 $G$，交集像素数为 $I$，则

$$IoU=\frac{|P\cap G|}{|P\cup G|}=\frac{TP}{TP+FP+FN},\qquad Dice=\frac{2TP}{2TP+FP+FN}.$$

当两者使用同一二值区域且分母非零时，$Dice=2IoU/(1+IoU)$。mIoU 是按类别求 IoU 后再平均，不是把所有类的交并集合并后做一次除法。大背景图中，预测全背景可能有很高的像素准确率，同时前景 IoU 为零，所以不能只报告准确率。

下面是简化教学代码，用混淆矩阵累计整个验证集。矩阵的行表示真值，列表示预测；把 (真值,预测) 编码成 C*真值+预测，即可一次统计所有组合。

Python
import numpy as np

def update_hist(hist, target, pred):
    c = hist.shape[0]
    valid = (target >= 0) & (target < c)
    assert np.all((pred[valid] >= 0) & (pred[valid] < c))
    codes = c * target[valid].astype(np.int64) + pred[valid]
    hist += np.bincount(codes, minlength=c*c).reshape(c, c)
    return hist

def mean_iou(hist):
    intersection = np.diag(hist)
    union = hist.sum(0) + hist.sum(1) - intersection
    present = union > 0
    if not present.any():
        return float('nan')
    return (intersection[present] / union[present]).mean()

hist.sum(1) 是每类真实像素数，hist.sum(0) 是每类预测像素数。先累计矩阵再计算可以避免最后一个小 batch 获得不合理权重。没有出现、也没有被预测的类别如何处理，要在实验协议中固定；本例忽略这类空并集，不能和“将空类别记为满分”的结果直接比较。

数据检查比换模型更早发生

图像与 mask 的随机裁剪、翻转、旋转必须使用同一组参数。图像缩放可以平滑插值，整数类别 mask 应使用最近邻。假设相邻类别是 1 和 4，双线性插值产生的 2 或 3 并不是新的真实标注。二值 mask 若特意保留软边界，需要连同损失定义一起明确，不能无意中混用。

检查一个 batch 时，应打印形状、类型、最小最大值、标签唯一值和前景比例，并把 mask 透明覆盖回原图。训练、验证、测试按原始样本来源拆分，增强图、同一患者切片、同一视频帧不能跨集合。训练损失下降只说明当前优化目标正在改善；边界质量、漏检、类别不平衡和跨来源泛化仍需独立验证。

小实验：为什么批次平均和整体统计不同

假设第一张图真实与预测前景都只有一个像素，而且完全重合，IoU 为 1；第二张图交集为 10、并集为 100，IoU 为 0.1。逐图平均得到 0.55，先合并交并集得到 11/101，约为 0.109。两者没有谁天然正确，前者让每张图权重相同，后者让大区域贡献更多。医学病例通常还需要患者层面的汇总，不能只凭一个总数字比较系统。

可以固定两张这样的人工 mask，手算后对照指标函数，确认它使用的是逐图、逐批还是全数据统计。这个实验不需要训练，却能提前发现评估接口错误。若两个模型只在不同前景大小的样本上表现不同，统计方式甚至可能改变优劣排序，所以实验报告应保留逐样本结果与整体混淆矩阵。

还有一种边界情况是图像和预测都没有前景。二值 Dice 的分母此时为零，加入平滑项通常会使它得到 1。空图很多时，简单逐图平均可能把模型表现抬高；应同时报告非空样本和空图的误检情况。训练中的软重叠损失与最终离散指标使用不同平滑方式，也应明确区分，避免把两个同名数值当成完全相同的定义。

练习：手算一次重叠

真实前景有 100 个像素，模型预测前景 80 个，其中 60 个正确。求 IoU 和 Dice；如果总图有 10000 个像素，像素准确率为何可能误导？

✅ 参考答案

交集为 60，并集为 100+80-60=120，因此 IoU=0.5，Dice=120/180≈0.667。错分像素只有 FP+FN=20+40=60，像素准确率仍为 99.4%。它掩盖了 40% 的真实前景被漏掉这一事实。

练习：输出形状错误

二值模型输出 [4,1,96,96]，对它执行 argmax(1) 后全黑，是模型必然没学会吗？

✅ 参考答案

不是。只有一个类别通道，argmax 必然返回索引零。应使用 logits[:,0]>0，或先 sigmoid 再以 0.5 为阈值，并单独检查 logits 的分布和真值标签。
