直方图与模板匹配：分布、对比度和局部相似度

🖼️ OpenCV 图像处理

两类统计，回答不同问题

直方图统计“多少像素落在某个数值范围”，忽略像素的排列位置；模板匹配保留局部排列，统计一个小图与大图各位置是否相似。它们都不直接理解对象语义，但能组成简洁、可解释的视觉流水线。后续信用卡识别会把模板匹配作为十分类器使用。

直方图的每个参数是什么意思

对于灰度图，$h(k)=\#\{(x,y):I(x,y)=k\}$；若除以参与统计的总像素数，则得到概率质量函数。calcHist([img], [0], mask, [256], [0,256]) 中，图像列表和通道列表是两种不同参数：[img] 提供输入，[0] 指定统计哪个通道。256 是桶数，范围右端不包含，因此像素 255 仍包含在最后一个桶内。

彩色图可分别统计 B、G、R，但三条边缘分布不能保留通道间的配对关系。两张结构完全不同的图也可能有相同直方图。例如把像素位置随机打乱，直方图不变，物体轮廓却消失。因此不能用“直方图一样”推断“图片一样”。

掩模形状是 (H,W)，非零处参与统计；不参与的位置不会因为显示成黑色就被记入灰度 0。下面的教学代码要求 gray 为单通道 uint8 图：

Python
import cv2
import numpy as np

mask = np.zeros(gray.shape, np.uint8)
mask[100:300, 100:400] = 255
hist_roi = cv2.calcHist([gray], [0], mask, [256], [0, 256])
selected = cv2.countNonZero(mask)
if selected:
    probability = hist_roi / selected

hist_roi 的形状为 (256,1)。当 ROI 超出图像边界，切片会被截到图像范围内，因此分母应取实际掩模像素数，不能一律写成 200×300。比较不同大小区域时，归一化后的分布通常比原始计数更便于判断。

均衡化为什么能拉开对比度

先由直方图得到累计分布 $F(k)=\sum_{j\le k}p(j)$，再把旧灰度映射到新灰度。原资料的直方图示意图 用 16 个像素演示累计概率映射；这解释了狭窄灰度区间如何扩展。整数取整、空桶和具体实现的端点处理会影响实际输出，不应要求均衡化后每个桶都严格一样高。

全局均衡化根据整幅图统计，明暗差异大的区域可能互相牵制，也可能放大噪声。CLAHE 可以改善这个问题：把图像分成局部网格，限制直方图峰值再调整对比度，并平滑衔接区域。tileGridSize=(8,8) 是网格划分，不是一个 8×8 像素的卷积核；clipLimit 控制对比度限制，而不是直接输出的像素上限。

Python
global_equalized = cv2.equalizeHist(gray)
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
local_equalized = clahe.apply(gray)

判断是否有益，应检查后续识别结果或可读性，而不是只看视觉上是否“更鲜艳”。对彩色图逐通道独立均衡会改变颜色比例，不能直接套用灰度结论。

模板输出不是原图大小

如果原图高宽为 $H,W$，模板为 $h,w$，以步长 1 在完全落入图像的区域滑动，得分图大小为 $(H-h+1,W-w+1)$。得分图的一个位置表示模板左上角放在那里，不是对象中心。用左上角加 (w,h) 就能画出右下角；这个坐标还属于原图坐标系。

平方差类 TM_SQDIFF、TM_SQDIFF_NORMED 越小越好；相关类 TM_CCORR 与去均值相关类 TM_CCOEFF 越大越好。归一化减少能量尺度的影响，但不能让模板自动适应任意旋转、大小或光照。CCOEFF_NORMED 的高分也不是模型给出的“80% 正确概率”。

下面用一个明确的匹配方法构造教学片段：

Python
score_map = cv2.matchTemplate(gray, template, cv2.TM_CCOEFF_NORMED)
min_value, max_value, min_loc, max_loc = cv2.minMaxLoc(score_map)
x, y = max_loc
h, w = template.shape[:2]
box = (x, y, x + w, y + h)

每一行分别完成滑动评分、取得极值、读取最佳左上角和恢复边界框。若改为平方差，需要改用 min_loc。模板不能大于搜索图，两个输入应有兼容的类型与通道。

多对象匹配与重复框

在 Mario 图中寻找金币时，用 np.where(score_map >= 0.8) 得到行、列数组，再反转次序组合成 (x,y)。zip(*loc[::-1]) 中的 * 是将序列展开为位置参数，不是“可选参数”。相邻位置通常会同时高分，因此一个金币可能产生多个矩形；扩展实现可按得分排序并抑制高度重叠的框。阈值应由当前模板和图像的分数分布选择。

观察最佳位置以外的分数

定位一个目标时，最好同时看得分图：清楚而孤立的高峰，比大面积相近高分更容易解释。如果背景中有重复条纹，多个峰值可能几乎一样；如果模板大部分是纯色，去均值后有效变化很少，评分也可能失去区分能力。应优先选择包含独特结构、边界清楚的模板，并用无目标图片检查误报情况。

  3. 当背景反复出现相同纹理，最佳模板分数高就足以认定目标存在吗？
