图像读写、数组与坐标：先读懂一张图

🖼️ OpenCV 图像处理

本节目标

计算机中的图像首先是数组。本节从读图、显示、裁剪、通道、填充和融合入手，建立后续 OCR、检测和跟踪都要使用的数据约定。学完应能在运行算法之前说明输入的高、宽、通道、数据类型与坐标系，并判断一次切片有没有改变原图。

像素、形状与颜色通道

彩色图像通常写成 $I\in\{0,\ldots,255\}^{H\times W\times3}$。数组的第一个轴对应行，也就是纵坐标 $y$；第二个轴对应列，也就是横坐标 $x$。所以读取一个像素用 image[y, x]，画一个点却把坐标写成 (x, y)。观察 shape、元素总数和 dtype 时，要把形状与数据类型联系起来：size 是数组元素个数，不是磁盘文件字节数。

OpenCV 读取的彩色通道顺序是 B、G、R；Matplotlib 显示彩色数组时按 R、G、B 解释。灰度图只有 (H, W)，不是“只留 B 通道”：灰度转换把颜色亮度信息组合到一个通道。直接把 BGR 数组传给 plt.imshow 会产生偏色，数组中的像素并没有被自动改成 RGB。

下面的教学代码演示读图失败检查、裁剪与显式颜色转换：

Python
import cv2
import numpy as np
import matplotlib.pyplot as plt

image = cv2.imread('cat.jpg')
if image is None:
    raise FileNotFoundError('未能读取 cat.jpg')
h, w = image.shape[:2]
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
roi = image[0:50, 0:200].copy()
red_only = image.copy()
red_only[:, :, :2] = 0
plt.imshow(cv2.cvtColor(red_only, cv2.COLOR_BGR2RGB))
plt.axis('off')
plt.show()

shape[:2] 同时适用于灰度和彩色图；image[0:50, 0:200] 的高度最多 50、宽度最多 200，右端点不包含在内。NumPy 的基础切片一般是共享内存的视图，后续修改 ROI 可能写回原数组，因此这里用 .copy()。red_only[:, :, :2] = 0 将 B、G 清零并保留 R；它得到三通道红色图，不是单通道灰度图。

边界、数值范围与融合

滤波窗口滑到图像边缘时，一部分窗口越界。常见填充方式包括复制边缘、反射、不重复端点的反射、环绕和常量填充。补什么值会改变边缘输出，因此比较两个卷积实现时，要同时核对核、深度和边界模式。

uint8 只有 0 到 255。对照数组加法与 cv2.add：对 uint8 数组，250 与 10 相加可能回绕成 4，OpenCV 饱和加法则得到 255。这不是显示问题，而是数值计算规则不同。需要保留超范围中间结果时，先转为浮点，再明确决定最后如何裁剪和显示。

注意 cv2.resize(image, (width, height)) 的参数顺序与 shape 相反；等比例缩放要用同一个比例，分别放大宽、高会改变物体形状。融合公式为 $J=\alpha A+\beta B+\gamma$，两张图的形状和类型应兼容。权重 0.4 与 0.6 的意思是逐像素加权，并不会自动对齐两张图里的物体。

Python
other = cv2.imread('dog.jpg')
if other is None:
    raise FileNotFoundError('未能读取 dog.jpg')
other = cv2.resize(other, (w, h))
mixed = cv2.addWeighted(image, 0.4, other, 0.6, 0)
ok = cv2.imwrite('mixed.png', mixed)
if not ok:
    raise OSError('图像保存失败')

视频循环为什么要先检查读取结果

视频就是按时间排列的帧。用一致的变量名保存读取状态，并避免使用 open 这样的内置函数名。每次读取后立即检查状态，才能在文件结束或解码失败时安全退出：

Python
cap = cv2.VideoCapture('test.mp4')
if not cap.isOpened():
    raise OSError('视频未打开')
try:
    while True:
        ret, frame = cap.read()
        if not ret or frame is None:
            break
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        cv2.imshow('video', gray)
        if cv2.waitKey(10) & 0xFF == 27:
            break
finally:
    cap.release()
    cv2.destroyAllWindows()

waitKey 既承担按键读取，也让本地窗口处理事件；等待 10 毫秒不意味着视频一定达到 100 FPS，因为解码与计算也耗时。Notebook 的 %matplotlib inline 是魔法命令，复制到普通 .py 文件时要移除。本页代码面向有 OpenCV 图形窗口支持的本地 Python，网站显示的是学习代码与解释。

把输入约定写成检查步骤

读一张新图时，可以先记录 (H,W,C)、最小值、最大值与数据类型，再观察一小块像素。若图像已经归一化为 0–1 浮点数，直接按 0–255 的阈值处理会得到几乎全黑的结果；若它是带透明通道的四通道图，直接解包为三个通道也会出错。这类错误通常发生在算法入口，越早检查，越容易定位。

ROI 坐标也要验证：裁剪条件至少应满足 0 <= x1 < x2 <= W 和 0 <= y1 < y2 <= H。边界框由浮点模型输出时，应明确取整方式，并先裁到图像范围，再判断裁剪是否为空。这样后续 resize 的报错才能与真正的上游定位问题分开。

为了复查处理结果，保存原始输入、用于计算的数组和用于显示的图片时应使用不同变量。画框和写字会改变像素，若把带有红框的图片重新送入阈值或直方图统计，展示操作就会污染计算。最简单的习惯是始终在 image.copy() 上绘图。

练习

  1. 一张形状为 (480, 640, 3) 的图，切片 image[100:200, 20:70] 的形状是什么？放大成宽 1280 且保持比例，传给 resize 的尺寸是什么？
  2. 为什么修改 image[:, :, 2] 可能直接改变原图，而修改 image.copy()[:, :, 2] 不会？
  3. 为 cv2.addWeighted 设计一个能检查是否饱和的单像素例子。
✅ 参考答案
  1. ROI 为 (100, 50, 3)；保持比例后的尺寸参数为 (1280, 960)。
  2. 前者是原数组的切片视图，后者先复制了独立内存。应区分变量名与底层数据是否共享。
  3. 例如两张单像素 uint8 图都填 200，令权重均为 1，数学结果为 400，饱和转换后的结果是 255。权重之和不一定必须是 1，但超范围的显示结果需要自己理解。
