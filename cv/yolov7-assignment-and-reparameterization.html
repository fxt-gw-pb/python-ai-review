YOLOv7：动态分配与重参数化

🎯 目标检测

把结构改进与训练策略分开理解

YOLOv7 仍然围绕多尺度特征、anchor 参数化和检测头工作，重点改进包括多分支特征聚合、训练时的正样本分配和部署时的结构合并。学习时可以沿两条路径阅读：图片经过哪些层得到三个尺度的预测；这些预测如何被分配标签并形成损失。

640×640 的常规三尺度模型输出 80×80、40×40、20×20。每个位置有 3 个 anchor，每个 anchor 输出 $C+5$ 个数。80 类时，图中常写的“85”指一个 anchor 的属性数；真正输出卷积的通道是 255。六类缺陷任务则为 33 通道。这个区分能解释网络图与张量打印看似不一致的问题。

多分支聚合的重点是路径

骨干配置中可以看到，多个连续卷积的不同中间结果被取出并拼接，再用 1×1 卷积融合。这类 ELAN 结构通过聚合不同长度的特征路径，保留不同变换深度的信息。读配置时，[-1,-3,-5,-6] 代表从当前层向前寻找四个输出，不是把同一个特征复制四次。

下采样模块常同时使用最大池化分支与步长 2 卷积分支，再拼接；SPPCSPC 聚合不同池化尺度与旁路特征。检测前的 RepConv 则为部署准备可合并的线性分支。模型的学习能力与部署成本分别受到连接方式、通道数和算子实现影响，不能用“分支越多越好”概括。

RepConv 为什么可以在推理时合并

训练时，一个 RepConv 将 3×3 卷积加 BN、1×1 卷积加 BN、可选的恒等 BN 分支相加，最后统一激活。推理时，BN 使用固定的运行均值 $\mu$ 和方差 $\sigma^2$，所以 Conv+BN 可以折叠为新的卷积：

$$ W'=\frac{\gamma}{\sqrt{\sigma^2+\epsilon}}W,\qquad b'=\beta+\frac{\gamma}{\sqrt{\sigma^2+\epsilon}}(b-\mu). $$

若原卷积没有 bias，令 $b=0$。再把 1×1 卷积核放到全零 3×3 核的中心，把恒等映射表示为中心位置的单位矩阵，就可以对三个卷积核与偏置分别求和。

Python
# 教学摘录：假设三个分支已各自完成 BN 融合
import torch.nn.functional as F

kernel = kernel_3x3 + F.pad(kernel_1x1, [1, 1, 1, 1]) + kernel_identity
bias = bias_3x3 + bias_1x1 + bias_identity

能相加的前提是分支的输入、输出、步长和采样对齐相容，而且激活在分支求和之后。若每个分支内部已经有非线性激活，就不能按这个式子合并。融合时必须使用评估模式的 BN 统计量，不能把随当前 batch 变化的训练 BN 当作固定线性变换。

验证融合应给转换前后模型同一输入，在 eval() 下比较最大绝对误差与实际检测结果，允许有限浮点误差。精度模式、导出后端、输入尺寸变化都可能影响数值，应在目标部署流程中验证。

IDetect 的两个隐式参数

课内检测头还使用 ImplicitA 和 ImplicitM：前者在卷积前添加可学习张量，后者在卷积后乘以可学习张量。其核心形式是 $y=m\odot(W(x+a)+b)$。当这些参数固定时，$Wa$ 可以并入偏置，输出乘数 $m$ 可以并入权重和偏置，所以推理路径能减少额外算子。

这些隐式参数是训练得到的参数，不是每张图片动态计算的注意力图。它们的合并与 RepConv 的分支合并属于不同操作，导出时要确认两者是否都已正确处理。

动态正样本分配：先筛候选，再竞争

首先按照真实框与 anchor 的宽高倍率进行初筛，并为接近网格边界的真实中心引入邻格候选。随后把当前图片所有尺度的候选合并，解码成像素框，计算真实框与候选框之间的 IoU 矩阵。若有 $M$ 个真实目标、$N$ 个候选，矩阵形状为 [M,N]。

对每个真实目标，取最多 10 个最高 IoU，求和并取整，至少保留 1，形成该目标的动态正样本数量。再综合分类代价与 IoU 代价，选择总代价最小的候选：

Python
# 教学摘录：pairwise_iou、class_cost 的形状均为 [M, N]
k = min(10, pairwise_iou.shape[1])
best_ious = pairwise_iou.topk(k, dim=1).values
dynamic_k = best_ious.sum(dim=1).int().clamp(min=1)
iou_cost = -(pairwise_iou + 1e-8).log()
cost = class_cost + 3.0 * iou_cost

dynamic_k 决定“选几个”，cost 决定“选哪些”。它们不能合并成只按 IoU 选固定 K 个框。若同一个候选被多个真实目标选中，再保留代价最小的匹配，防止一个预测承担互相冲突的监督。

这里的动态 K 描述初步选取数量，冲突消解后各目标保留数量还可能变化。候选集合为空时也需要专门处理，否则 topk 或拼接会失败。

辅助头做什么

较大输入的 P6 系列可以采用四尺度主头与辅助头，训练时增加中间监督。辅助分配可以更宽松，帮助增加正样本覆盖；最终预测以主头为核心。辅助头不是普通三尺度模型中必然存在的固定结构，也不意味着部署时必须保留两套输出。

课内 loss_ota 配置决定是否启用动态分配，常规训练与辅助训练入口不同。复现时应先确认使用的模型配置、训练脚本与损失类型相匹配。不能只把图像尺寸改到 1280，就假定已经变成四尺度辅助头模型。

从训练失败定位到具体环节

标签加载失败时先检查数据列表中的机器路径；类别正确但 loss 异常时检查 anchor 单位与类别维度；某尺度一直没有正样本时检查目标尺度分布、初筛阈值及候选解码。部分旧实现空张量直接放在 cuda:0，这在 CPU 或其他设备运行时可能造成设备不一致，应该由已有张量的设备决定新张量位置。

训练结果需要通过固定验证集比较。重参数化主要改变推理图，不能期待仅执行融合就提升模型学习到的识别能力；它的收益要用一致条件下的实际延迟、显存和输出误差验证。

练习：动态 K 与重参数化

某真实目标的最高 5 个 IoU 为 0.9、0.8、0.4、0.2、0.1，动态 K 是多少？为什么先在每条卷积分支后加 ReLU，就不能直接把卷积核求和？

✅ 参考答案

IoU 之和为 2.4，取整后动态 K=2；最终按总代价选择两个候选，不一定恰为 IoU 最大的两个。ReLU 是非线性的，一般有 ReLU(a)+ReLU(b) 不等于 ReLU(a+b)，因此分支内激活破坏了简单线性合并条件。
