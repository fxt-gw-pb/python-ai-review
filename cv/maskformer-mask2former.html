MaskFormer 与 Mask2Former：区域查询和掩码注意力

🧩 图像分割

版本提示：这份 Mask2Former 实现基于 2.x

本章的 Mask2Former 工程使用 MMDetection 2.25.2，与目标检测章节中的 3.0.0rc3 是两份不同年代的代码，不能共用一套配置假设。截至 2026-09-05，官方最新正式版为 3.3.0；当前 3.x 的训练引擎、配置和数据接口与 2.x 有明显变化。先用本章掌握 query、mask、匹配与注意力的算法逻辑，迁移工程时再按目标版本整体核对依赖和配置。官方发布记录 · 2.x → 3.x 配置迁移

从像素分类到 mask 分类

传统语义分割对每个像素预测类别。MaskFormer 换一个角度：先预测一组区域 mask，再给每个区域预测类别。每个预测由“类别分布 + 二值区域概率图”组成。多个预测可以属于同一类别，因此这套表示也能表达不同实例。

模型输出的 query 数 $Q$ 不等于类别数 $C$。query 是预测区域的槽位，某张图不需要的槽位预测为 no-object；每个 query 可以在不同图像中表示不同类别，不是固定绑定一个词。语义分割将同类区域合并，实例分割保留个体，全景分割还要处理像素归属及 stuff 区域合并。

三个模块与关键形状

骨干产生多尺度特征；pixel decoder 将它们融合为密集像素特征；Transformer decoder 更新 query 表示。对 [B,Q,D] 的 query 表示，一条线性分类头输出 [B,Q,C+1]，额外一类是 no-object；另一条 MLP 输出 mask embedding，与 [B,D,H,W] 像素特征做通道点积。

$$z_{bqhw}=\sum_d e_{bqd}f_{bdhw},\qquad m_{bqhw}=\sigma(z_{bqhw}).$$

所有 query 共享像素特征，只使用不同 embedding 读取它们。生成 mask 的原样核心代码只有一行：

Python
mask_pred = torch.einsum('bqc,bchw->bqhw', mask_embed, mask_feature)

c 在点积中求和，b 保留 batch，q 保留预测区域，h,w 保留空间位置。不能在 query 轴上 softmax 强迫每个像素只属于一个 query；训练阶段各 mask 独立 sigmoid，后处理再按任务解决重叠。

语义融合可使用 $S_c(h,w)=\sum_q p_q(c)m_q(h,w)$，再在类别维取最大值。这里的聚合分数不必天然和为 1，因此称为类别得分更严谨。全景后处理则结合类别置信度、mask 概率与区域保留率，将像素分配给某个区域。

匈牙利匹配：让预测集合找到对应真值

预测槽位没有固定顺序，真实对象也没有唯一排序。如果直接把第一个 query 和第一个标注配对，同一图中标注顺序改变就会改变训练目标。因此先构造 [Q,N_gt] 代价矩阵，综合类别代价、mask 代价与 Dice 代价，再求总代价最低的一对一匹配。

匹配确定后，匹配上的 query 学习对应类别和 mask，其余 query 学习 no-object。匹配过程本身不通过离散索引求导；反向传播发生在被匹配的预测损失上。MaskFormer 使用 focal 与 Dice 的区域损失；Mask2Former 的示例配置使用 BCE 与 Dice，不能只凭继承类名称判断实际损失。

Mask2Former：注意力只看当前候选区域

MaskFormer 的 cross-attention 面向全图。Mask2Former 用上一层的 mask 预测限制下一层注意力范围：被认为是背景的位置加 $-\infty$，保留位置加 0。

$$X_l=\operatorname{softmax}\left(Q_lK_l^T/\sqrt d+M_{l-1}\right)V_l+X_{l-1}.$$

$M$ 是用于注意力的屏蔽矩阵，不是目标真值，也不是 Dropout。模型在自身当前判断的区域里提取局部特征，再通过 query 间的 self-attention 交换信息，逐步修正区域。

代码先把 mask logits 插值到下一层特征分辨率，展平成空间轴，为各注意力头复制，再转为布尔屏蔽。原样核心节选如下。

Python
attn_mask = attn_mask.flatten(2).unsqueeze(1).repeat(
    (1, self.num_heads, 1, 1)).flatten(0, 1)
attn_mask = attn_mask.sigmoid() < 0.5
attn_mask = attn_mask.detach()

形状为 [B*heads,Q,H*W]，True 表示禁止关注。detach 使离散阈值不承担梯度路径，mask 本身仍通过区域损失训练。若某 query 屏蔽了所有位置，softmax 将没有有效输入，因此实现会将该行全部改回 False，让它重新观察图像。

多尺度轮换与点采样监督

pixel decoder 输出三个供注意力读取的尺度，通常为输入的 1/32、1/16、1/8。九层 Transformer decoder 按 level_idx=i%3 轮流使用，而不是把所有高分辨率特征一次拼给每层。这样兼顾小物体信息与计算成本。

query_feat 是初始查询内容，query_embed 是查询位置表示；二者分别可学习，含义不同。模型在进入第一层之前就预测一次，再对九层输出分别监督，因此会看到十组中间预测损失。层数九不代表只有九次监督。

高分辨率 mask 损失占用大量内存。实现匹配时为所有预测和真值采同一组随机点，保证代价公平；最终损失则偏向不确定点并混合随机点。配置中的 12544 是每张 mask 采样点数，不是将输出图固定改为 112×112。完整输出仍是空间 mask。

配置文件也是模型的一部分

示例配置将实例分割打开，语义与全景关闭，thing 类为 80、stuff 为 0。训练 pipeline 读取 mask，做大范围尺度扰动、裁剪、过滤空对象、padding 和归一化。类别数、class_weight 长度、数据集类别映射、fusion head 与评估类型应一致。

自定义演示配置的 train、val、test 使用同一小数据集合，只能用于验证训练流程。正式实验必须拆分独立数据。同时检查迭代学习率：若训练总共只有 10000 步，而衰减点仍在 30 多万步，整个实验就不会触发预期衰减。不能因为配置名包含某个 epoch 数，就认定实际训练长度与名称相符。

该实现属于一套完整的历史 mmdetection 配置与模块接口，阅读继承关系时需要同时看 detector、head、pixel decoder、assigner 和 fusion head。尤其语义输出不能只靠打开布尔开关：本示例的 semantic_postprocess 直接抛出 NotImplementedError，需要补齐后处理才能输出语义结果。

匹配代价和最终损失不能只看名字

匹配阶段需要比较每个预测与每个真实区域，因此产生一个二维代价矩阵；最终损失只计算选定匹配对，再对 no-object 槽位计算分类监督。两者即使都含有交叉熵或 Dice，归约维度与权重作用位置也不同。阅读时应先标出输入和输出形状，再追踪配置是否覆盖默认代价。

推理置信度同样包含两个来源：类别得分衡量这个区域属于某类的把握，mask 得分反映前景区域内部的像素概率。将它们组合后排序，可以抑制类别很自信但 mask 几乎没有有效前景的预测。只有空 mask 时分母还需平滑，避免得到无定义分数。

练习：屏蔽方向

mask 概率低于 0.5 的位置得到 True，表示更关注还是不关注？如果整行都是 True 怎么办？

✅ 参考答案

此处 True 表示不允许关注。整行屏蔽会让注意力没有可用位置，因此代码把它恢复为全 False，重新允许访问所有位置；这不等于把该 query 的预测 mask 强制设为全前景。

练习：query 数与类别数

数据有 150 类，模型使用 100 个 query，是否必然无法预测所有类别？

✅ 参考答案

不是。每个 query 都有 151 维类别输出，query 数限制单张图可表达的区域槽位，而非整个数据集词表大小。真正需要检查的是单图目标区域数量是否经常超过 query 容量。
