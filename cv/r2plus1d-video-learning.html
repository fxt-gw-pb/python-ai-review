R(2+1)D：视频时空卷积与数值回归

🧩 图像分割

视频建模：时间轴不能被忽略

单张图像只能描述某一时刻的外观，视频还包含运动顺序与变化速度。心腔收缩、人的动作或物体交互往往依赖多帧关系。视频模型通常输入 [B,C,T,H,W]，其中 $T$ 是采样帧数；先理解时间采样，再比较网络结构，才能避免把不同信息量的输入拿来做不公平对比。

R2D、R3D 与 R(2+1)D 的差别

二维卷积只在高宽方向滑动。把多帧堆进通道，可以让模型混合固定帧位置的信息，但没有显式的时间平移卷积结构，也会把输入通道数绑定到片段长度。逐帧二维特征再平均则保留外观统计，却丢掉大部分顺序信息。

三维卷积同时沿时间、高、宽滑动，核大小为 $k_t\times k_h\times k_w$。它直接学习局部时空模式。混合卷积网络在部分层用 3D，其他层用 2D，用于研究何处需要时间建模。R(2+1)D 则把一个时空卷积拆成空间卷积和时间卷积两步，并在中间加入非线性。

模块 卷积核 主要作用
空间卷积 1×kh×kw 每帧内提取纹理与形状
时间卷积 kt×1×1 比较同位置相邻帧的变化
残差捷径 恒等或投影 保持维度匹配与梯度路径

时间卷积仍可用 Conv3d 表达，只是空间核为 1×1；这里“1D”指只沿时间建模，不代表必须把数据先变成一维数组。

参数量为什么不一定更少

忽略偏置，原始 3D 卷积参数量为

$$P_{3D}=C_{in}C_{out}k_tk_hk_w.$$

若中间通道为 $M$，分解后的参数量为

$$P_{2+1D}=C_{in}Mk_hk_w+MC_{out}k_t.$$

因此可以选择

$$M=\left\lfloor\frac{C_{in}C_{out}k_tk_hk_w}{C_{in}k_hk_w+C_{out}k_t}\right\rfloor$$

使参数量接近原始 3D 卷积。结构分解的收益还包括中间多一次非线性与不同优化路径，不能简化为“拆开以后参数必然更少”。比较时应同时控制通道数、参数量、片段长度、采样间隔和训练设置。

实现一个形状清楚的分解块

下面为简化教学代码，只展示 stride=1、奇数卷积核的情况。

Python
import torch
from torch import nn

class SpatialTemporalBlock(nn.Module):
    def __init__(self, in_channels, out_channels, mid_channels):
        super().__init__()
        self.body = nn.Sequential(
            nn.Conv3d(in_channels, mid_channels, (1, 3, 3),
                      padding=(0, 1, 1), bias=False),
            nn.BatchNorm3d(mid_channels),
            nn.ReLU(inplace=True),
            nn.Conv3d(mid_channels, out_channels, (3, 1, 1),
                      padding=(1, 0, 0), bias=False),
            nn.BatchNorm3d(out_channels))
        self.skip = (nn.Identity() if in_channels == out_channels else
                     nn.Conv3d(in_channels, out_channels, 1, bias=False))

    def forward(self, x):
        return torch.relu(self.body(x) + self.skip(x))

第一层保持 $T,H,W$，将通道变为 mid_channels；第二层仍保持空间尺寸，但沿时间比较三帧。捷径将输入通道映射为 out_channels，才能与主分支相加。完整网络在部分阶段还会下采样时间或空间，届时捷径的 stride 也必须相应变化。

片段采样决定模型看到多少运动

若取 $L$ 帧、间隔为 $p$，索引是 $s+p\cdot[0,1,\ldots,L-1]$。首尾跨越 $(L-1)p$ 个原始帧间隔，而不是 $Lp$。例如 16 帧、间隔 4、50 FPS，首尾相距 60/50=1.2 秒。输入张量仍只有 16 帧，增大间隔扩大时间覆盖，却降低时间采样密度。

短视频需要 padding 或其他明确处理。若先标准化再补零，零表示训练均值对应颜色，不再是原始黑色。应该保存有效帧信息或至少检查短视频占比，避免模型利用 padding 长度作为非目标线索。多个片段的空间增强还应保持时间一致，逐帧随机裁剪会制造假的运动。

从动作分类网络改成数值回归

视频案例将最后的 fc 改为输出一个数，训练用均方误差：

$$MSE=\frac1B\sum_i(\hat y_i-y_i)^2.$$

目标为回归数值，因此不在最终输出上做类别 softmax。形状 [B,1] 可以 reshape 为 [B] 与标签对齐；但要避免误广播成 [B,B]，那会比较每个预测与所有标签。

推理可以从同一个视频取多个片段，输入从 [B,K,C,T,H,W] 临时合并成 [B*K,C,T,H,W]，模型前向后再恢复 [B,K,1]，对片段求平均。block_size 控制一次送入多少片段，以限制显存，它不是采样间隔，也不是视频 batch size。

评价应该回到视频或患者单位

MAE 表示平均绝对误差，RMSE 对大误差更敏感，$R^2$ 比较模型相对常数均值预测的解释能力。回归标签以百分数 0 到 100 表示，还是比例 0 到 1 表示，会使 MAE 与 RMSE 相差 100 倍，记录时必须明确单位。

同一视频多个片段不是独立患者。最终指标应先将片段汇总成视频预测，再按视频或患者评价；置信区间抽样也应保持同源分组。若按照展开后的片段数累计“样本数”，可能使长视频在平均误差中获得更大权重。增加片段数改善平均稳定性，也增加推理成本，应同时报告策略。

设计公平的时空模型对照

若要比较三维卷积和分解卷积，先固定每个视频的采样起点或保存采样随机种子，保证模型看到的内容一致。再固定输入帧数、帧间隔、训练划分和目标单位；否则一个模型看到了完整动作，另一个只看到了短暂静止片段，结构结论就不可靠。

还可以增加逐帧二维模型加平均池化的基线。如果二维基线已经接近视频模型，说明当前目标可能主要由静态外观决定，或者时间信息尚未被有效利用。将帧顺序打乱后性能是否明显下降，也是探索模型是否利用时间关系的实验，但应在固定评估设计中进行，避免把这种扰动混进正常性能报告。

最后观察错误与视频长度、运动速度和采样稀疏度的关系。较快运动在大间隔采样下可能被跳过，较慢运动在短片段中又可能几乎没有变化。适当扩大覆盖范围与增加采样密度会带来不同成本，应根据任务变化的时间尺度选择，而不是一味增加帧数。

练习：时间覆盖

32 帧、采样间隔 2、原视频 30 FPS，首尾帧的时间跨度是多少？

✅ 参考答案

首尾相距 (32-1)×2=62 个原始帧间隔，即 62/30≈2.067 秒。不能直接用 32/30，因为输入不是连续每帧采样。

练习：片段指标为何虚高

把一个视频的 20 段分别当成 20 个独立测试样本，会有哪些问题？

✅ 参考答案

它们高度相关，会夸大独立样本数；视频片段数量不同时还会改变各视频权重。应先按视频汇总预测，再按独立视频或患者计算指标及不确定性。
