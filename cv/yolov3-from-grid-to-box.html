YOLOv3：从网格到边界框

🎯 目标检测

网格预测为什么能变成目标框

YOLOv3 把输入图像交给 Darknet 骨干网络，利用三种分辨率的特征生成检测结果。以 416×416 输入为例，三个检测网格为 13×13、26×26、52×52，对应步长 32、16、8。每个网格位置使用 3 个 anchor，每个 anchor 预测中心偏移、宽高变换、目标性分数和类别分数。

设类别数为 $C$，每层输出卷积的通道数为 $3(C+5)$。80 类时为 255；5 类时为 30。这与 YOLOv1 的 $S\times S\times(B\times5+C)$ 不同：v1 的类别分数按网格共享，v3 为每个 anchor 分别预测类别。不能直接把不同代模型的输出公式互换。

跟踪一次形状变化

对于 batch 大小 $B$、网格边长 $G$，检测头的原始输出为 [B,3(C+5),G,G]。为了让每个候选的属性连续存放，代码进行：

Python
prediction = raw.view(B, 3, C + 5, G, G)
prediction = prediction.permute(0, 1, 3, 4, 2).contiguous()

第一行只是重新解释维度；第二行把属性维移到最后，得到 [B,3,G,G,C+5]。permute 后内存排列通常不连续，contiguous() 生成适合后续 view 的连续布局。若缺少维度移动，即使元素总数相同，也会把不同位置的值误认为同一候选的属性。

三层候选总数为 $3(13^2+26^2+52^2)=10647$，80 类推理输出形状为 [B,10647,85]。这还不是最终物体数量，大多数候选是背景，需要置信度筛选和 NMS。

中心受约束，宽高相对 anchor 缩放

令网格位置为 $(g_x,g_y)$，步长为 $s$，以输入像素为单位的 anchor 为 $(a_w,a_h)$。网络输出 $t_x,t_y,t_w,t_h$，解码公式为：

$$ c_x=(\sigma(t_x)+g_x)s,\quad c_y=(\sigma(t_y)+g_y)s, \qquad w=e^{t_w}a_w,\quad h=e^{t_h}a_h. $$

Sigmoid 将中心限制在当前网格内部；指数使宽高为正，并允许相对 anchor 任意放大。若 $t_w=0$，预测宽度恰等于 anchor 宽度。训练标签则反向变换为网格内偏移与对数宽高比例，例如 $t_w^*=\log(w^*/a_w)$。

课内实现先把 anchor 除以 stride 转为网格单位，再在输出时统一乘 stride。理解中间单位，可以解释为什么“anchor 乘了两次 stride”会得到巨大框。指数也可能放大极端输出，因此输入、标签异常或学习率过大时应关注宽高数值与非有限损失。

三个尺度如何互相帮助

Darknet 的残差连接是逐元素相加，要求两条分支形状一致；检测部分的 route 则按通道拼接，允许通道数不同，但空间尺寸必须一致。深层特征经过上采样，与较早的高分辨率特征拼接，再进行卷积与预测。

这样做的原因是：深层特征包含较强语义信息，但空间网格粗；浅层特征定位更细。融合让小目标检测头既能保留位置细节，又利用较深语义。高分辨率输出并不意味着每个点只看到一个很小的原图区域，感受野仍由前面的网络决定。

配置解析器逐层读取 convolutional、upsample、route、shortcut 与 yolo，生成 ModuleList。训练时模型按相同顺序执行并保存中间特征；route 用索引取旧输出，shortcut 把旧输出与当前分支相加。读配置时应同时记录层号、空间尺寸和通道数，单看模块名称很容易漏掉跨层连接。

正样本与忽略区域

build_targets 把归一化真实框乘以当前网格大小，得到中心所在单元与网格单位宽高。随后只比较真实框与 anchor 的宽高 IoU，为当前检测层选出最匹配的 anchor。该位置成为正样本，其类别标签设为 one-hot，回归目标写入中心偏移和对数宽高张量。

同一位置上其他与真实框比较相似的 anchor 可以从背景损失中忽略。忽略不等于正样本：忽略位置既不承担该框的回归，也不被强行作为背景惩罚。这个区分在拥挤目标或多个相似 anchor 中尤其有用。

课内实现分别在各检测层构造目标，因此应按实现检查匹配范围，不要想当然地认为每个真实框只会在全网络贡献一个正样本。

损失与训练循环逐段理解

该实现对中心与对数宽高使用 MSE，对目标性和类别概率使用 BCE。框回归和分类只在正样本位置计算，目标性还覆盖大量背景位置，并使用单独权重。训练日志中的每个分量对应不同任务；目标性损失很大时，先检查正负样本与标签读取，不宜立即改变骨干网络。

梯度累积用于让多个小 batch 的梯度共同形成一次参数更新。下面是一般训练循环的教学写法，包含最后不足一组的情况：

Python
optimizer.zero_grad()
for i, (images, targets) in enumerate(loader):
    loss, _ = model(images, targets)
    group_start = (i // accumulation) * accumulation
    group_size = min(accumulation, len(loader) - group_start)
    (loss / group_size).backward()
    if (i + 1) % accumulation == 0 or i + 1 == len(loader):
        optimizer.step()
        optimizer.zero_grad()

除以当前累积组的 batch 数，使这一组按平均损失更新。课程旧循环用取模结果直接当条件，不能推广为“每累积 K 次更新一次”；例如 K=1 时余数永远为 0，反而不会更新。理解条件比直接复制训练循环更重要。

迁移到自己的类别

改动类别数时，三个 [yolo] 层的 classes 和它们前一层的 filters=3(C+5) 必须一致，还要同步类别名称文件与数据列表。生成自定义配置的脚本采用追加写入，重复运行会把网络再追加一遍，应该先生成到新文件并检查结构。

首次训练先读一个 batch，打印 [B,3,H,W] 与 [N,6]，把框画回图像，再做一次前向与反向。历史代码中的机器固定路径、字节类型 mask 与调试打印，也应在迁移环境时逐项检查。

预训练权重如何进入模型

Darknet二进制权重与PyTorch检查点使用不同保存格式。二进制文件开头包含版本与已见图片数量，后面依次保存BN参数或卷积偏置，再保存卷积核。读取顺序与网络层顺序必须对应，否则即使读取字节数足够，也可能把数值放错位置。只加载骨干预训练与加载完整检测权重的范围不同；更换类别后，旧分类检测层通常不能按原尺寸直接复用，应保留可兼容的骨干并重新初始化新的输出层。

练习：手算一个候选框

输入 416×416，检测层 stride=32，网格位置为 $(2,3)$，anchor 为 $(64,32)$。若四个预测参数都为 0，中心和宽高是多少？五类别检测头每个尺度的卷积输出通道数是多少？

✅ 参考答案

Sigmoid(0)=0.5，exp(0)=1，因此中心为 $(80,112)$，宽高为 $(64,32)$。五类别时，每个 anchor 输出 10 个数，每点 3 个 anchor，卷积通道数为 30。把中心误算为 $(2.5,3.5)$，说明仍停留在网格坐标；把宽高再乘 32，则是重复应用 stride。
