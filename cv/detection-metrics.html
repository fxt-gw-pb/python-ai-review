目标检测任务、IoU、NMS 与 mAP

🎯 目标检测

从分类到检测：模型究竟要回答什么

图像分类给一张图片一个或几个类别，目标检测则要输出一个长度可变的集合：每个元素包含类别、边界框和置信度。同一张图可以没有物体，也可以有几十个物体。因此，检测系统不只是把分类网络最后一层换大，还需要解决位置表示、正负样本分配、重复预测与集合评估。

可以先用四个组件理解大多数检测器：骨干网络提取特征，特征融合网络连接不同分辨率，检测头生成候选结果，后处理把候选结果整理成最终集合。两阶段方法先提出候选区域，再对区域分类与回归；单阶段方法直接在特征上预测类别与框。这里的“阶段”描述算法流程，不能直接推导出任何数据集上的速度和精度排名。

边界框与 IoU：先统一坐标，再谈正确

常见表示包括左上右下坐标 $(x_1,y_1,x_2,y_2)$，以及中心宽高 $(c_x,c_y,w,h)$。连续坐标下，$w=x_2-x_1$、$h=y_2-y_1$。有些旧实现按包含两个端点的整数像素计算宽高，会额外加 1。两种约定不能混用，尤其是小框；宽度从 2 变成 3，会显著改变面积。

IoU 衡量预测框 $A$ 与真实框 $B$ 的重叠程度：

$$ \operatorname{IoU}(A,B)=\frac{|A\cap B|}{|A|+|B|-|A\cap B|}. $$

计算交集时，左上角取两框坐标的最大值，右下角取最小值。交集宽高必须截断到非负数，否则不相交的框会产生错误的正面积。下面是可运行的连续坐标教学实现：

Python
def iou_xyxy(a, b):
    ix1, iy1 = max(a[0], b[0]), max(a[1], b[1])
    ix2, iy2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0.0, ix2 - ix1) * max(0.0, iy2 - iy1)
    area_a = max(0.0, a[2] - a[0]) * max(0.0, a[3] - a[1])
    area_b = max(0.0, b[2] - b[0]) * max(0.0, b[3] - b[1])
    return inter / max(area_a + area_b - inter, 1e-9)

前两行求相交矩形；第三行处理不相交情形；最后一行避免空框导致除零。真实训练前仍应拒绝宽高非正的标注，而不能靠分母中的小数掩盖数据错误。

三个阈值分别控制什么

置信度阈值决定哪些预测被保留；NMS 的 IoU 阈值决定哪些同类预测被认为重复；评估时的 IoU 阈值决定预测与真实框是否足够接近。它们解决三个不同问题，数值可以相同，含义却不能合并。

标准贪心 NMS 先按分数降序排序，取最高分框，再删除与它同类且 IoU 超过阈值的候选，重复直到没有候选。YOLO 中常见的类别分数是目标性分数与类别条件分数的乘积。课内 YOLOv3 实现还会对重叠框坐标做置信度加权平均，因此它包含“合并框”行为，并非最简单的只删框 NMS。

Soft-NMS 对重叠预测降低分数，保留之后再次参与排序的机会。密集目标中，过强抑制容易把相邻真实物体删掉；阈值过松则增加重复框。调整阈值时应同时查看漏检与重复检测图片，而不是只盯着框的数量。

TP、FP、FN 与一对一匹配

一个预测成为 TP，需要类别正确、位置达到评估 IoU 阈值，而且对应真实目标尚未被更高优先级预测匹配。对同一真实物体预测两个正确框，通常只能有一个 TP，另一个属于重复检测 FP。真实目标没有匹配到合格预测就是 FN。

$$ P=\frac{TP}{TP+FP},\qquad R=\frac{TP}{TP+FN}. $$

检测中的背景位置没有自然、有限且统一的枚举方式，所以通常不以 TN 为核心指标。分类准确率也不能代替检测质量：一张图中存在“猫”不意味着猫的位置正确，更不意味着所有猫都被找到了。

从排序表手算 AP

假设只有一个类别，共有 3 个真实目标，按置信度排序后的预测依次为 TP、FP、TP、TP。累计精确率为 $1,1/2,2/3,3/4$，累计召回率为 $1/3,1/3,2/3,1$。

AP 汇总整条精确率—召回率曲线。全点插值先构造精确率包络：每个召回位置取右侧可达到的最高精确率；再对召回率增加的区间求面积。下面保留了课内 AP 实现的主要计算步骤：

Python
import numpy as np

def interpolated_ap(recall, precision):
    r = np.r_[0.0, recall, 1.0]
    p = np.r_[0.0, precision, 0.0]
    p = np.maximum.accumulate(p[::-1])[::-1]
    changed = np.where(r[1:] != r[:-1])[0]
    return np.sum((r[changed + 1] - r[changed]) * p[changed + 1])

反向累计最大值构造包络；changed 只保留召回率变化的位置，防止同一召回位置重复计面积。上述例子的全点插值 AP 为 $1/3+1/3\times3/4+1/3\times3/4=5/6$。VOC 早期的 11 点插值与这个算法不同；COCO 常用 AP 还会综合 IoU 从 0.50 到 0.95、步长 0.05 的多个阈值，并采用其规定的召回采样与目标数量限制。报告结果时应明确是 AP50 还是 AP50:95。

怎么解释一组实验结果

AP50 较高而 AP75 较低，常提示模型大体找到了物体，但框定位不够精确。小目标 AP 低，可以检查缩放后目标还剩多少像素、标注是否稳定、较高分辨率特征是否参与预测。训练损失下降而验证 AP 不动，也可能是类别顺序、坐标还原或评估实现出错，并不总是模型容量不足。

公平比较至少固定数据划分、输入尺寸、测试增强、后处理及指标实现。速度需要注明设备、批量大小与是否计入预处理和 NMS。一次前向传播的毫秒数不能直接代表整个应用的端到端延迟。

指标实现也需要小样例验证

先构造只有一个真实框的场景：完全相同的同类预测应为TP，错类预测应为FP，第二个同类重复框也应为FP。再加入一张没有目标的背景图，确认高置信度误报会降低精确率。最后检查没有任何预测时的行为：程序应返回可解释的零召回结果，而不是出现空数组拼接或除零错误。用这些小例子验证评估器，比拿一个大数据集的总分猜测实现是否正确更直接。

练习：发现重复检测

某类别有 2 个真实框。按分数从高到低的三个预测分别正确匹配第一个真实框、重复匹配第一个真实框、正确匹配第二个真实框。最终 P、R 是多少？为什么不能把三个预测都计为 TP？

✅ 参考答案

最终 TP=2、FP=1、FN=0，所以 P=2/3、R=1。同一真实实例只能贡献一次成功检测，否则重复输出就能人为提高召回率。这里还应注意：NMS 删除重复框可能改善 P，但如果两个真实物体重叠，NMS 也可能误删其中一个，因此需要评估数据与可视化共同验证。
