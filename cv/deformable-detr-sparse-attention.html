Deformable DETR：稀疏多尺度注意力

🎯 目标检测

为什么原始 DETR 会在高分辨率上变贵

原始 DETR 编码器让每个图像 token 与所有 token 计算注意力。设特征图有 $S=H_fW_f$ 个位置，注意力矩阵包含约 $S^2$ 个元素。若特征图长宽都翻倍，token 数增加四倍，注意力矩阵规模增加十六倍。这使直接引入高分辨率特征来检测小目标变得昂贵。

另一个问题是训练初期注意力分布可能较分散，模型要从大量位置中逐渐学会关注物体。Deformable DETR 用可学习的少量采样点替代对所有位置的密集读取，在保留关系建模的同时降低图像注意力开销。

三个量：参考点、偏移、注意力权重

每个 query 首先有一个参考点 $p_q$。网络根据 query 特征预测若干二维偏移 $\Delta p_{qk}$ 与权重 $A_{qk}$，从 $p_q+\Delta p_{qk}$ 处读取特征，再加权求和。单头单尺度的核心可以写成：

$$ o_q=\sum_{k=1}^{K}A_{qk}\,V(p_q+\Delta p_{qk}),\qquad \sum_k A_{qk}=1. $$

参考点提供初始位置，偏移决定具体采样位置，权重决定采样值的贡献。偏移是连续实数，不必落在整数像素上；它也不是预先写死的固定 3×3 邻域。不同 query 可以学习适合不同物体的采样形状。

与普通点积注意力不同，这里的采样偏移和权重通过 query 特征的线性投影生成，不需要先为当前 query 与整张图每个 key 都计算点积。模型仍包含多头投影和后续变换，不能因此把它当作简单裁剪几个像素。

双线性插值为什么关键

采样坐标通常落在像素之间。若直接四舍五入选最近像素，位置变化可能长时间不改变采样值，难以通过梯度学习位置。双线性插值根据相邻四个网格值与距离，连续地计算采样值，因此在大部分位置都能向采样坐标传递梯度。

下面是单尺度、单头、已归一化坐标的教学模块，不包含完整注意力中的线性投影：

Python
import torch
import torch.nn.functional as F

def sparse_sample(feature, locations, weight_logits):
    # feature: [B,C,H,W]
    # locations: [B,Q,K,2]，最后一维按 x,y，取值使用 [0,1] 坐标
    # weight_logits: [B,Q,K]
    grid = locations * 2 - 1
    sampled = F.grid_sample(feature, grid, mode='bilinear',
                            padding_mode='zeros', align_corners=False)
    weights = weight_logits.softmax(dim=-1)
    return torch.einsum('bcqk,bqk->bqc', sampled, weights)

grid_sample 接收的网格范围是 [-1,1]，所以先进行线性转换。此处输出采样张量为 [B,C,Q,K]，einsum 沿 K 维求和，得到 [B,Q,C]。在 align_corners=False 约定下，原特征像素 $(x,y)$ 的中心对应归一化位置 $((x+0.5)/W,(y+0.5)/H)$，不能简单用 $x/(W-1)$ 替代。

越界位置按零填充处理，这个行为会影响边缘目标。采样点、padding mask 与图像有效范围都应保持一致。

多尺度如何放到一个序列中

完整模型从骨干取三个尺度，再生成一个更低分辨率尺度，通常一共四层，每层投影到 256 通道。每层展平后沿位置轴拼接，形成长度 $S=\sum_lH_lW_l$ 的序列。

仅保存拼接后的值还不够。spatial_shapes 记录每层的 (H_l,W_l)，level_start_index 记录每层在长序列中的起始位置，valid_ratios 记录补边后有效宽高比例，level embedding 区分尺度身份。这些辅助信息让算子能找到“第 l 层上的某个二维位置”。

假设四层大小为 80×80、40×40、20×20、10×10，序列长度为 8500，起始位置是 [0,6400,8000,8400]。起点不是各层边长的累计，而是各层空间面积的累计。

多尺度注意力每个头在每个尺度取 K 个点，并在所有尺度与采样点组成的集合上归一化权重。若 8 个头、4 个尺度、每层 4 点，每个 query 一共涉及 128 个采样位置；不是让每个头仍然读取全部 8500 个位置。

编码器与解码器替换的位置

编码器的图像自注意力换成多尺度可变形注意力；解码器从图像读取信息的 cross-attention 也换成可变形注意力。query 之间的自注意力仍使用普通多头注意力，因为 query 数相对有限，实例之间的交流仍有价值。

多尺度信息已经能通过注意力交换，所以不一定还需要额外 FPN。课内框架配置使用 ChannelMapper 对齐通道并补充尺度，再由注意力融合。通道对齐层与 FPN 的自顶向下融合并不是同一个模块。

在 logit 空间逐层细化边界框

参考点通常由 query 位置向量经过线性层与 sigmoid 得到。框预测相对参考点调整，而不是每层都从零猜一个全新中心。对于已经归一化的参考框 $b^{(l-1)}$，可写成：

$$ b^{(l)}=\sigma\left(\Delta b^{(l)}+\sigma^{-1}(b^{(l-1)})\right). $$

在 sigmoid 的输入空间加偏移，再映射回 [0,1]，可以保持坐标范围。实际代码要先把参考值限制在远离 0、1 的范围，防止 inverse sigmoid 产生无穷。

Python
import torch

def refine_reference(reference, delta, eps=1e-5):
    r = reference.detach().clamp(eps, 1 - eps)
    logits = torch.log(r / (1 - r))
    return torch.sigmoid(logits + delta)

这里 detach() 对应逐层细化时阻断参考框这一条反传路径，当前层仍通过 delta 学习更新。若只有二维参考点，则中心利用参考点细化，宽高由另两维输出预测；四维参考框时，中心和宽高都可以逐层更新。

两阶段变体与训练设置

两阶段 Deformable DETR 可以从编码器位置生成候选框，挑出分数较高的候选作为解码器初始输入，再逐层细化。这里的两阶段不等于 Faster R-CNN 的 RPN+RoIAlign 结构，仍应根据实际模块理解。

课内配置使用 300 个 queries、FocalLoss 分类、L1 与 GIoU 框损失，仍通过匈牙利匹配提供一对一监督。骨干、采样偏移与参考点投影可以使用较小学习率，以减少已预训练特征和几何采样位置的剧烈变化。报告“收敛更快”时必须同时说明训练计划、数据与对比条件，不能把论文中的固定轮数差直接解释为任意设备上的时间倍率。

练习：检查稀疏采样

两层特征大小为 4×4 和 2×2，level_start_index 应是什么？参考坐标0.5、预测增量0时，细化后的坐标是多少？

✅ 参考答案

起始位置为 [0,16]，总长度为20。参考0.5的logit为0，加上零增量再sigmoid，结果仍是0.5。这个例子也说明delta表示相对修正；delta为零并不把所有框推到同一个位置，而是保留原参考值。
