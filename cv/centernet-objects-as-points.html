CenterNet：把目标表示为中心点

🎯 目标检测

不先列出很多框，直接寻找中心

CenterNet 把一个物体表示成边界框中心，再在中心位置预测宽高与细微偏移。网络输出三类信息：每个类别的中心热力图、中心位置的小数偏移、物体宽高。它不需要为每个位置预设多个长宽比，也不通过 anchor 与真实框的 IoU 阈值来定义中心正样本。

以输入 512×512、输出步长 $R=4$、类别数 $C$ 为例，热力图形状为 [B,C,128,128]，偏移图为 [B,2,128,128]，宽高图为 [B,2,128,128]。宽高与偏移在这一结构中跨类别共享，热力图则为每类保留独立通道。

真实中心如何放到特征图

设原图真实框中心为 $p=(c_x,c_y)$。先映射到特征图坐标 $p/R$，再取整数部分 $\tilde p=\lfloor p/R\rfloor$。整数网格承担中心检测，小数部分由 offset 回归恢复：

$$ o^*=p/R-\lfloor p/R\rfloor. $$

若原图中心为 $(101,78)$，除以 4 后是 $(25.25,19.5)$。整数中心为 $(25,19)$，offset 为 $(0.25,0.5)$。没有 offset，量化误差最多接近一个特征单元，换回原图就是数个像素，对小目标会更显著。

高斯热力图不是“周围都是正样本”

以整数中心为峰值，在相应类别热力图上绘制高斯：

$$ Y_{xyc}=\exp\left(-\frac{(x-\tilde p_x)^2+(y-\tilde p_y)^2}{2\sigma_p^2}\right). $$

中心值为 1，周边逐渐变小，目标越大通常允许较大的高斯范围。同类目标的高斯重叠时取逐元素最大值，不直接相加，否则峰值可能超过 1。

训练中，精确中心 Y==1 是正样本；周边 $0<Y<1$ 的位置仍走负样本分支，只是惩罚被减弱。热力图损失可以写成：

$$ L=-\frac1N\sum_{xyc} \begin{cases} (1-\hat Y)^\alpha\log\hat Y,&Y=1,\\ (1-Y)^\beta\hat Y^\alpha\log(1-\hat Y),&Y<1. \end{cases} $$

$(1-Y)^\beta$ 降低中心附近的负样本惩罚，让模型不用因非常小的位置偏差受到过强惩罚。这个设计与把高斯数值直接当作普通 BCE 的软标签不同。

宽高和偏移只在中心监督

热力图对全图计算损失，宽高和 offset 则只在真实中心位置读取预测并计算 L1。因为其他位置没有对应物体，强迫所有位置回归某个框尺寸没有合理意义。代码通过 [B,2,H_f,W_f] 的权重图标记哪些回归位置有效。

一个教学版目标生成片段如下，统一使用特征图单位：

Python
# box_xyxy 是原输入图坐标；stride 为特征图步长
x1, y1, x2, y2 = box_xyxy
cx, cy = (x1 + x2) / (2 * stride), (y1 + y2) / (2 * stride)
ix, iy = int(cx), int(cy)
wh_target[:, iy, ix] = wh_target.new_tensor(
    [(x2 - x1) / stride, (y2 - y1) / stride])
offset_target[:, iy, ix] = offset_target.new_tensor([cx - ix, cy - iy])
regression_mask[:, iy, ix] = 1

iy,ix 的索引顺序与几何书写的 x、y 相反，这是图像数组经常出错的地方。宽高有的实现使用输入像素单位，有的使用特征图单位；必须查看目标生成与解码是否一致。下面的解码统一采用特征图单位宽高，因此恢复到输入图时，中心与宽高都需要乘 stride。

从热力图恢复框

先对热力图做 3×3 最大池化，保留与邻域最大值相等的位置；再选分数最高的一批中心。每个中心读取 offset 与宽高，得到角点。

Python
import torch
import torch.nn.functional as F

def decode_one_center(heatmap, wh, offset, stride=4):
    # 单图：heatmap [C,H,W]，wh/offset [2,H,W]
    pooled = F.max_pool2d(heatmap.unsqueeze(0), 3, stride=1, padding=1)[0]
    peaks = heatmap * (heatmap == pooled)
    flat_index = int(peaks.reshape(-1).argmax())
    _, height, width = heatmap.shape
    cls = flat_index // (height * width)
    spatial = flat_index % (height * width)
    y, x = divmod(spatial, width)
    center = offset[:, y, x] + offset.new_tensor([x, y])
    size = wh[:, y, x]
    box = torch.cat([center - size / 2, center + size / 2]) * stride
    return cls, peaks[cls, y, x], box

这个教学函数只解码最高分的一个中心，用于检查坐标链路。完整实现还要批处理、Top-K、阈值过滤、边界处理和缩放还原。flat_index 同时编码了类别与空间位置，除法恢复类别，取余恢复空间索引。

这里的局部极大值过滤本身是一种热力图上的抑制操作。因此“CenterNet 不需要 NMS”更准确的含义是：基础单尺度流程不依赖对候选框逐对计算 IoU 的 NMS。多尺度测试合并结果时，或某些框架开启可选后处理时，仍可能使用框 NMS。

输出分辨率怎样提高

检测骨干下采样后，可以使用转置卷积、插值与卷积或多层特征聚合恢复较高分辨率。转置卷积不是普通卷积的数值逆运算。普通卷积可写作 $y=Ax$，转置卷积对应类似 $A^Ty$ 的运算，并不保证还原原来的 $x$。

对一维尺寸，转置卷积输出为 $(H_{in}-1)s-2p+d(k-1)+output\_padding+1$。例如输入长度 3、核大小 3、stride=2、padding=1、dilation=1、output_padding=0，输出为 5。理解尺寸公式，可以在换骨干或上采样层时快速排查监督热力图与预测尺寸不一致的问题。

能力边界与扩展任务

如果同一类别的两个目标量化到同一个中心单元，单份宽高回归无法同时描述两个框。共享宽高还使不同类别在同一位置发生几何竞争。高分辨率输出可以减少碰撞，但密集目标仍要做实际检查，不能把“没有 anchor”理解为解决了所有重叠问题。

相同中心表示还可扩展到姿态与三维属性：增加中心到关节的偏移、深度、三维尺寸或方向分支。它们需要相应监督与单位约定，并不是额外加几个通道就能自动学会三维结构。

把三种输出分开诊断

热力图负责找到中心，所以漏检首先可以查看真实中心附近是否有足够高的峰值。若峰值位置正确而框大小明显不对，重点检查宽高目标、回归权重与单位；如果所有框都有不到一个 stride 的系统偏移，优先检查 offset 是否读取了正确的位置。只看最终画框无法区分这三种错误。

可以设计一个无需训练的管线检查：直接用真实标注生成热力图、宽高和偏移目标，再交给解码函数，比较恢复框与原框。若仍不一致，说明目标生成、索引或坐标还原存在问题。这个实验验证的是几何管线，不代表网络已经学会检测。

损失权重也要结合量纲理解。热力图损失处理概率，宽高损失可能处理数十甚至数百像素的数值，偏移通常处于0到1之间。如果更改宽高单位，却不重新考虑损失权重，相同数字的权重会产生不同的优化强度。先固定单位，再比较权重设置，实验才有可解释性。

练习：检查坐标恢复

网格位置 $(25,19)$，offset 为 $(0.25,0.5)$，特征图单位宽高为 $(10,6)$，stride=4，恢复的中心、宽高和角点分别是什么？

✅ 参考答案

中心为 $(101,78)$，宽高为 $(40,24)$，角点为 $(81,66,121,90)$。如果宽高只得到 $(10,6)$，说明漏乘 stride；如果中心变为 $(100.25,76.5)$，说明先恢复整数中心、却忘了给 offset 同样乘 stride。
