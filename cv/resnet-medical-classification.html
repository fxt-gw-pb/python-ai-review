ResNet 医学分类：残差结构与任务评估

🧩 图像分割

ResNet 医学图像分类：先建立可靠基线

分类基线回答“这张图属于哪个类别”，适合先验证数据读取、标签定义和训练流程。它与分割任务共享卷积骨干，却不提供逐像素边界。本章用小尺寸医学数据理解残差块、任务类型和评估，避免从复杂模型开始就把所有问题混在一起。

残差连接让网络学习修正项

普通模块直接学习 $H(x)$，残差模块学习 $F(x)$，再输出

$$y=\operatorname{ReLU}(F(x)+S(x)).$$

当维度相同，$S(x)=x$；当通道数或空间步长变化，使用 1×1 卷积投影捷径。残差提供直接的信号与梯度路径，有助于训练较深网络，但不能理解为“准确率保证不下降”。优化方式、数据和泛化都会影响最终结果。

示例 BasicBlock 的主分支由两个 3×3 卷积组成。第一个卷积可以 stride=2 下采样，第二个保持尺寸。若从 [B,64,28,28] 变为 [B,128,14,14]，捷径也必须变成 [B,128,14,14]，否则无法相加。

下面是 BasicBlock 前向的原样核心节选。

Python
out = F.relu(self.bn1(self.conv1(x)))
out = self.bn2(self.conv2(out))
out += self.shortcut(x)
out = F.relu(out)
return out

第一行提取并激活特征，第二行继续变换但暂不激活，第三行加入捷径，最后再激活。Bottleneck 则用 1×1、3×3、1×1 的三段结构，中间控制通道、末尾扩展通道，expansion=4 会影响后续层的输入维度。

小图像骨干与大图像骨干的差别

这里输入通常为 28×28，小图骨干使用 3×3、stride=1 的起始卷积，没有立即采用大步长把图像压小。ResNet18 四个阶段采用 [2,2,2,2] 个 BasicBlock。空间尺寸沿途为 28、28、14、7、4；末尾 4×4 平均池化得到 1×1，再展平并分类。

阶段 ResNet18 输出形状
起始卷积 / 第一阶段 [B,64,28,28]
第二阶段 [B,128,14,14]
第三阶段 [B,256,7,7]
第四阶段 [B,512,4,4]
池化与分类 [B,512] → [B,C]

固定 4×4 池化与当前尺寸相配。若改为更大输入，展平向量可能不再是 512；可使用 AdaptiveAvgPool2d(1) 明确目标输出尺寸，但这属于结构修改，需要重新核对训练与权重兼容。

数据集接口决定标签与损失

MedMNIST 数据类从 npz 中分别读取 train_images、val_images、test_images 及对应标签，用 PIL 包装单张图像，再应用变换。数据配置提供通道数、类别字典和任务类型。不能因为文件都叫医学图像，就默认全部是互斥二分类。

互斥分类每张图只有一个类别，logits 形状 [B,C]，标签应为 [B] long，使用 CrossEntropyLoss。多标签任务每张图可以同时有多个属性，标签为 [B,C] float，使用 BCEWithLogitsLoss。前者输出 softmax 概率，后者各通道独立 sigmoid。

下面是简化教学代码。

Python
logits = model(images)
if task == 'multi-label, binary-class':
    targets = targets.float()
    loss = torch.nn.functional.binary_cross_entropy_with_logits(logits, targets)
    scores = logits.sigmoid()
else:
    targets = targets.reshape(-1).long()
    loss = torch.nn.functional.cross_entropy(logits, targets)
    scores = logits.softmax(dim=1)

reshape(-1) 保留 batch size 为 1 时的一维标签；无参数 squeeze() 可能把 [1,1] 直接压成标量。多标签分支不应展平，否则会混淆样本轴与类别轴。图像通道由数据配置确定，灰度 1 通道与彩色 3 通道都必须与第一层卷积一致。

AUC 与准确率回答不同问题

准确率依赖分类决策：互斥分类取最大类别，多标签按阈值分别判断。AUC 评价分数对正负样本的排序能力，不能先二值化再计算 AUC，否则会丢失排序信息。多类代码采用 one-vs-rest：把每个类别当成正类，分别算 AUC，再平均。

某个验证子集若只出现某类正样本或负样本，对应 ROC AUC 无法定义。应该报告缺失情况并检查拆分，而不是把异常分数填成零后假装是正常评估。类别分布偏斜时，还应查看逐类表现与混淆矩阵，整体准确率可能被多数类支配。

训练脚本每轮计算验证 AUC，并选验证 AUC 最大的断点用于最终测试。这比按训练准确率选模型合理，但前提是验证集独立，测试集没有参与调参。只要同一患者或高度相似切片跨集合，评价就可能虚高。

实验复现需要保存什么

除模型权重，还需保存数据集版本、样本划分、类别映射、输入通道、标准化参数和最佳轮数。如果恢复训练，需要优化器与调度器状态；单纯加载选中的模型只能重建预测参数。检查训练是否正常时，先用少量固定样本验证损失是否能下降，再进行完整实验。

报告性能时，应附清晰的数据拆分和评估设置，让结果具有可比较的含义。

用混淆矩阵决定下一步改哪里

当总准确率上升时，先看是否所有类别都有改善。假设少数类只占百分之五，模型完全忽略它仍可能得到较高整体准确率；逐类召回能直接暴露这种遗漏。如果训练与验证的类别比例不同，单一准确率的变化也可能来自分布差异，而非模型表示能力。

对错误样本可以按真值类别、预测类别和置信度分组。高置信度误判适合检查标签是否含混、图像是否来自异常来源以及训练集是否缺少类似样本；低置信度样本可能需要更细致的类别定义或更高分辨率。修改之前先确认数据与任务，避免把所有错误都归咎于网络层数不足。

灰度和彩色归一化也应做实际数值检查。若像素从零到一被变换为减去零点五再除以零点五，输入范围约为负一到一；如果再次除以二百五十五，范围会过度缩小。把输入均值、标准差与首批特征打印出来，可快速判断问题是否已经发生在模型之外。

练习：为何不能统一 softmax

一张图可以同时具有两种标签，使用两个输出通道的 softmax 是否合适？

✅ 参考答案

不合适。softmax 强制两类概率和为 1，表达的是互斥关系。应使用独立 sigmoid 与逐类二元损失，并为每个标签保存真值与分数。

练习：投影捷径

主分支从 64 通道、28×28 变为 128 通道、14×14，捷径需要怎样设置？

✅ 参考答案

使用输入 64、输出 128、kernel_size=1、stride=2 的卷积，并按结构设置归一化，使捷径输出与主分支同形后相加。
