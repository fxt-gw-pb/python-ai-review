U-Net 与 U-Net++：医学细胞分割

🧩 图像分割

U-Net：压缩语义，再恢复位置

分割需要同时知道“这是什么”和“边界在哪里”。编码器经过池化逐步降低分辨率，获得较大范围的上下文；解码器逐步上采样恢复空间细节。U-Net 的关键是在对应分辨率之间建立跳跃连接，把浅层较清晰的边缘信息拼接给深层特征。

相加要求通道数一致，并直接混合两个表示；拼接则保留两组特征，再由后续卷积学习如何组合。若两个特征分别为 [B,32,H,W] 与 [B,64,H,W]，沿通道轴拼接后为 [B,96,H,W]。卷积块把 96 通道压到目标通道数，这也是读代码时首先要核对的维度。

用 96×96 输入走一遍编码器

示例网络使用两次 3×3 卷积、BatchNorm 和 ReLU 组成 VGGBlock，padding 为 1，因此块内空间尺寸不变。四次 2×2 池化带来的变化如下。

节点 通道数 空间大小
$X^{0,0}$ 32 96×96
$X^{1,0}$ 64 48×48
$X^{2,0}$ 128 24×24
$X^{3,0}$ 256 12×12
$X^{4,0}$ 512 6×6

最终 1×1 卷积把 32 通道变为类别通道，不承担空间缩放。输出仍是 logits，二值任务是 [B,1,96,96]。如果输入尺寸经过连续池化后不能准确乘二恢复，拼接会失败；教学时用显式 size=skip.shape[-2:] 对齐，比假定所有输入都能整除更清晰。

U-Net++：跳跃路径也学习特征

U-Net++ 在编码器和最终解码器之间增加嵌套卷积节点。同一尺度的节点不仅接收下一级上采样结果，也接收前面已经构建的同尺度节点。可写为

$$X^{i,j}=H\left([X^{i,0},\ldots,X^{i,j-1},U(X^{i+1,j-1})]\right),\quad j>0.$$

$H$ 表示卷积块，$U$ 表示上采样，方括号表示通道拼接。这样，浅层信息沿途经过卷积变换后再与深层语义融合，而不是永远通过一条未经处理的长连接。

下面是网络前几个节点的原样核心节选，省略了形状打印。

Python
x0_0 = self.conv0_0(input)
x1_0 = self.conv1_0(self.pool(x0_0))
x0_1 = self.conv0_1(torch.cat([x0_0, self.up(x1_0)], 1))
x2_0 = self.conv2_0(self.pool(x1_0))
x1_1 = self.conv1_1(torch.cat([x1_0, self.up(x2_0)], 1))
x0_2 = self.conv0_2(torch.cat([x0_0, x0_1, self.up(x1_1)], 1))

第三行拼接 32+64=96 通道，卷积后回到 32；最后一行拼接 32+32+64=128 通道，同样回到 32。不要把节点下标当成网络层数：第一个下标表示尺度深度，第二个下标表示同尺度融合阶段。

深监督如何改变训练

启用 deep_supervision 时，顶层四个不同阶段分别经过输出头，得到四张同分辨率预测。训练对四个输出分别计算损失，然后平均：

$$L=\frac14\sum_{j=1}^{4}L_j.$$

梯度因此能够从多个路径回传。验证若规定只用最后一个输出，就必须一直遵守同一策略；平均四个概率图是另一种推理规则，不能不说明就替换。较浅输出头可用于速度取舍，但真正加速需要裁掉不再使用的后续计算，仅返回较浅结果却照算整个网络不会节省多少时间。

细胞实例 mask 在预处理中被求并集后，任务已经变成“所有细胞核的前景区域”。这种标签适合二值语义分割，却不再保存相邻细胞的身份，不能直接据此宣称完成细胞实例计数。

BCE 与 Dice 的组合

示例 BCEDiceLoss 先用 logits 计算稳定二元交叉熵，再 sigmoid 得到概率，按样本展平计算软 Dice，最终返回 0.5*bce + dice_loss。交叉熵提供逐像素的监督，Dice 对前景整体重叠更敏感。这里损失中的软 Dice，与先以 0.5 阈值二值化再计算的 IoU 指标，数值含义不同。

预处理与验证中的三个关键修正

第一，图像采用标准化增强后，不应在 Dataset 里再次除以 255。假如增强已经执行 $(I/255-\mu)/\sigma$，再除以 255 会把标准化分布压缩。应选择一处负责归一化，并检查训练与推理完全一致。

第二，mask 缩放应使用最近邻。原始的二值标签如果被线性缩放，会产生软边界；若实验没有明确设计软标签，这会改变监督目标。下面是简化修正版的关键处理。

Python
mask = cv2.resize(mask, (96, 96), interpolation=cv2.INTER_NEAREST)
augmented = transform(image=rgb_image, mask=mask)
image = augmented['image'].astype('float32').transpose(2, 0, 1)
target = (augmented['mask'] > 0).astype('float32')[None]
# transform 已负责 image 的 Normalize，这里不再 /255。

第三，验证导出的概率图与显示图应遵守相同阈值。直接把 logits 与 0.40 比较，对应的不是 40% 概率。批次 IoU 的加权平均也不严格等于整个验证集交并集之比，实验记录应固定统计方式。

一个节点如何获得多条梯度路径

观察顶层第二个融合节点，它接收原始浅层特征、已经融合一次的浅层特征和更深尺度上采样的特征。这三路虽然分辨率相同，语义处理深度却不同。后续卷积不是简单投票，而是为所有输入通道学习权重。某条路径中包含另一条路径的加工结果也不是错误，它让网络同时保留原始表示和逐步变换后的表示。

深监督给中间头增加直接损失后，这些节点不再只能等待最深输出端的梯度。学习者可以把各头损失分别记录，检查是否某个浅头长期停滞。若只打印四项平均值，一项大幅恶化可能被其他项改善抵消。对同一个验证样本画出四张概率图，可以观察前景范围、粘连和边缘随融合深度如何改变，但不要把个别好看的图当成总体指标。

最后，对比普通 U-Net 与嵌套版本时，应固定划分、预处理、损失、输入尺寸和评价阈值。若嵌套模型用了深监督而基线没有，实验同时改变了结构与训练目标；可以再加一组关闭深监督的嵌套模型，分辨改善主要来自哪里。结构更复杂也意味着更多中间特征和显存占用，精度与推理成本需要一起观察。

练习：密集拼接通道数

若顶层已有四个 32 通道节点，下一级上采样结果为 64 通道，那么 $X^{0,4}$ 卷积块应接收多少通道？

✅ 参考答案

接收 4×32+64=192 通道。后续卷积可以输出 32 通道。拼接增长的是输入通道数，不要求输出通道也随节点数量增长。

练习：为何 IoU 高却不能数细胞

两个相邻细胞被预测成连通的一块，总前景区域很准确，可以用该结果证明实例分割很好吗？

✅ 参考答案

不能。前景 IoU 不关心同类个体身份。若要评估实例分割，需要保留每个细胞的独立 mask，并评估实例匹配、漏检和粘连；合并后的语义标签无法监督这些区别。
