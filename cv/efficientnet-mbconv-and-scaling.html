EfficientNet：MBConv、SE 与复合缩放

🎯 目标检测

骨干网络要同时考虑表达能力和计算量

检测器的骨干网络把像素转换成多级特征。浅层分辨率高，保留边缘和纹理；深层分辨率低，表达较抽象的语义。更强的骨干可以改善检测，但它不是独立决定结果的因素：数据质量、特征融合、输出头与训练策略都会影响最终表现。

EfficientNet 的一个出发点是协调网络深度、宽度和输入分辨率。深度增加变换次数，宽度增加每层通道，分辨率保留更多输入细节。单独扩大其中一个维度会遇到收益递减，也可能让其他部分成为瓶颈。

用卷积公式理解复合缩放

忽略 bias，一个普通卷积的参数量约为 $K^2C_{in}C_{out}$，乘加次数约为 $H_{out}W_{out}K^2C_{in}C_{out}$。如果所有通道扩大 $w$ 倍，输入长宽扩大 $r$ 倍，层数扩大 $d$ 倍，则总计算量可粗略按 $dw^2r^2$ 理解。

因此通道与分辨率不是线性成本：宽度翻倍，前后通道同时扩大，单层计算量常接近四倍；图像长宽翻倍，空间位置也增加四倍。这个估算有助于挑选实验方向，但实际延迟还受内存访问、算子实现和设备并行能力影响。

代码并不直接接受任意小数通道数。round_filters 先乘宽度系数，再对齐到指定倍数，并避免取整后比理论值小太多；round_repeats 对重复次数乘深度系数后向上取整。理解取整规则，才能解释两个模型规模参数不同，却有部分层通道完全相同的现象。

深度可分离卷积省在哪里

普通 3×3 卷积同时混合空间与通道；深度卷积对每个输入通道独立执行空间卷积，不在这一步混合通道。再接 1×1 点卷积，负责通道之间的信息交换。

普通卷积成本为 $HWK^2C_{in}C_{out}$；深度可分离卷积约为 $HW(K^2C_{in}+C_{in}C_{out})$。以 $K=3$、输入输出通道都为 64 为例，每个位置普通卷积需要 36864 次乘加，而深度加点卷积需要 4672 次。这个数字说明理论计算量下降，但不保证在所有硬件上获得同等比例加速。

Python
import torch.nn as nn

spatial = nn.Conv2d(64, 64, kernel_size=3, padding=1,
                    groups=64, bias=False)
channel_mix = nn.Conv2d(64, 128, kernel_size=1, bias=False)

groups=64 让 64 个通道分别卷积；后面的 1×1 卷积把通道从 64 混合到 128。若 groups 只是 2 或 4，则是一般分组卷积，不等于逐通道的 depthwise 卷积。

MBConv：先扩张，再投影

MBConv 的“倒残差”来自通道结构：先用 1×1 卷积把输入扩展到较宽的中间空间，再做 depthwise 卷积和通道注意力，最后投影回输出通道。扩张比为 6 时，输入 [B,32,H,W] 的中间通道可扩展为 192。

如果 stride=1 且输入输出通道相同，才具备直接残差相加的形状条件；stride=2 会改变空间尺寸，通常不能直接加回输入。扩张比为 1 时，也可以省略第一层扩张卷积。

模块中的 Swish 可写成 $f(x)=x\sigma(x)$，让负数区间仍有平滑输出。最后的投影与 BN 后没有继续使用同样的非线性压缩，便于在较窄的输出空间保留信息。判断结构时应逐行看激活放置位置，而不是把所有 Conv 后面都自动补一个激活。

SE：一张图生成一组通道权重

SE 先对每个通道做全局平均池化，把 [B,C,H,W] 压成 [B,C,1,1]。接着用两层 1×1 变换先压缩、后恢复通道数，经 sigmoid 得到通道权重，乘回原特征。

Python
# 教学摘录：se_reduce、se_expand 是可学习的 1×1 卷积
import torch
import torch.nn.functional as F

pooled = F.adaptive_avg_pool2d(features, 1)
hidden = se_reduce(pooled)
hidden = hidden * torch.sigmoid(hidden)
weights = torch.sigmoid(se_expand(hidden))
reweighted = features * weights

weights 的最后两个维度为 1，因此乘法会广播到同一通道的所有空间位置。SE 强调“哪些通道重要”，并没有为每个像素单独生成空间注意力。它也不同于跨图片共享的固定缩放参数：权重取决于当前图片的特征。

课内 MBConv 的 SE 压缩通道按原始输入通道与 se_ratio 计算，而不是始终按扩张后的通道数计算。例如输入 32、扩张到 192、se_ratio=0.25 时，中间压缩通道为 8。这个细节直接影响参数量。

Drop connect 与检测特征抽取

可跳连的 MBConv 在训练时可以随机丢弃整条残差分支，保留恒等路径，并按保留概率调整输出幅度。课内实现的随机 mask 形状为 [B,1,1,1]，意味着同一图片的该分支整体保留或丢弃，不是随机删除每个像素。评估模式会关闭这个随机过程。

用于检测时，EfficientNet 不再只返回分类 logits。包装器删除最后分类头，取出骨干若干下采样阶段的输出。以 B0 的检测接法为例，供检测使用的 P3、P4、P5 通道为 40、112、320，空间步长分别为 8、16、32。之后要先通过 1×1 卷积统一通道，才能送入逐元素相加的特征融合层。

如何做有意义的缩放实验

先固定训练策略与数据划分，以较小骨干建立基线，再单独尝试更大分辨率或更大骨干。记录每类 AP、目标尺度 AP、峰值显存和实际推理时间。若小目标只剩几像素，提高分辨率可能比增加深度更直接；若模型对清晰大目标仍识别困难，可以进一步检查语义表达与数据覆盖。

批量较小时还要关注 BN 的统计稳定性。冻结 BN、使用预训练统计还是继续更新，都是需要实验记录的训练选择。切换 eval() 会同时影响 BN 和随机正则化，不能把它当成“只是不求梯度”。

练习：看懂注意力形状

输入 [2,32,64,64]，扩张比为 6，stride=2，输出通道为 48。depthwise 后、SE 全局池化后、投影后的形状分别是什么？能否直接与输入相加？

✅ 参考答案

扩张后为 [2,192,64,64]，stride=2 的 depthwise 后为 [2,192,32,32]，SE 池化后为 [2,192,1,1]，投影后为 [2,48,32,32]。它不能直接与原输入相加，因为空间尺寸与通道数都不一致。SE 权重乘回特征时，利用最后两个维度为 1 的广播完成计算。
