阈值、平滑与形态学：把目标从背景中分离

🖼️ OpenCV 图像处理

从任务决定预处理

预处理的目的，是让下一步需要的结构更容易被提取。信用卡数字要保留亮字符、连成数字组；答题卡要把涂黑区域变成可计数的白色前景；文档扫描要保留纸张边界。相同的“二值化加形态学”在三种任务中会使用不同的前景极性、核大小和操作顺序。

先灰度或颜色空间转换，再选择阈值与平滑，最后讨论集合形状的变化。HSV 将色调、饱和度与明亮程度分开，可以帮助写颜色筛选规则，但把 HSV 数组直接作为普通彩色图显示并不会还原真实颜色。

五种阈值，五种不同问题

对于像素 $p$、阈值 $T$ 和最大输出值 $M$，二值阈值是 $p>T$ 时输出 $M$，否则为 0；反二值正好相反。截断阈值把大于 $T$ 的数压到 $T$。TOZERO 将不大于 $T$ 的值清零，其余保留；TOZERO_INV 则保留低值并清除高值。不要把五种方法都称为“黑白化”，截断和置零结果仍可能保留多个灰度级。

阈值 127 是演示选值，不是适用于所有图的经验最优值。threshold 返回两项：实际采用的阈值与输出图。后续项目使用 Otsu 自动阈值时，第一项很有诊断价值：它反映当前图的灰度分布，而不是一个可跨场景通用的常数。

Python
import cv2
import numpy as np

gray = np.array([[40, 127, 200]], dtype=np.uint8)
threshold, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
_, truncated = cv2.threshold(gray, 127, 255, cv2.THRESH_TRUNC)
# binary: [[0, 0, 255]]；truncated: [[40, 127, 127]]

等于阈值的像素没有超过阈值，所以二值结果是 0；这一边界细节可以用三元素数组验证，没必要靠肉眼猜整张图片。

平滑不是越模糊越好

下面比较四类滤波。均值滤波把窗口内值平均；归一化方框滤波做同样的求和除以窗口面积，未归一化时只求和，若输出仍是 uint8，大值会饱和。高斯滤波给靠近中心的像素较大权重，窗口和标准差控制平滑程度。中值滤波取邻域排序后的中间值，对孤立的极亮、极暗噪点有用，而且它不是固定权重的线性卷积。

选择滤波必须联系目标尺度：3 像素宽的细字符经大核平滑后可能断笔或粘连。比较平滑效果时，不只看背景是否“干净”，还要观察边缘位置、细线宽度和小目标是否保留。彩色均值操作保持三个通道，拼接显示要求各结果高度和通道数一致。

腐蚀、膨胀与结构元素

对白色前景，腐蚀要求结构元素覆盖的位置都属于前景，因而缩小白区；膨胀只要窗口内有前景就扩张白区。对灰度形态学，可把腐蚀理解为邻域最小值，膨胀理解为邻域最大值。若输入是黑字白底而目标是黑字，应先想清楚“前景”究竟指什么，否则会把变细与变粗解释反。

结构元素不仅有尺寸，也有形状。矩形核能沿指定方向连接结构，椭圆核更适合近似圆形目标。np.ones((3, 3), np.uint8) 的尺寸按行列表示；getStructuringElement(..., (9, 3)) 的尺寸参数则是宽、高。用 30×30 大核和 1、2、3 次迭代可以观察形状变化趋势，但参数不能直接沿用到所有分辨率。

运算 组合方式 适合观察的结构
开运算 先腐蚀，再膨胀 去除比核小的白色噪点、断开细桥
闭运算 先膨胀，再腐蚀 填补小黑洞、连接邻近白块
形态学梯度 膨胀减腐蚀 目标边界带
礼帽 原图减开运算 比局部背景更亮的小结构
黑帽 闭运算减原图 比局部背景更暗的小结构

代表代码逐段读

下面的教学片段中，输入 binary_image 是一张白色前景的单通道二值图：

Python
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
opened = cv2.morphologyEx(binary_image, cv2.MORPH_OPEN, kernel)
closed = cv2.morphologyEx(opened, cv2.MORPH_CLOSE, kernel)
outline = cv2.morphologyEx(closed, cv2.MORPH_GRADIENT, kernel)

第一行确定将被删除或连接的空间尺度；第二行先删除孤立小白点；第三行尝试补洞；第四行提取处理后边界。这个顺序只是演示，不是固定流水线：开运算已删除的小字符，闭运算无法可靠恢复。必须保留原图和各中间图，逐步确认信息损失。

若手动计算迭代 5 次的膨胀与腐蚀，再与默认迭代次数的 MORPH_GRADIENT 比较，条件就不一致。两幅边界带宽度不同，并不说明梯度定义错误。对照实验必须使用相同核和迭代设置。

练习

  1. 为什么白色数字被腐蚀后会变细？如果数字为黑色，结论是否仍成立？
  2. 数字之间出现间隔，需要合并为水平方向的数字组，应优先尝试什么核和运算？
  3. 为什么中值滤波不可以用一个固定的 3×3 权重矩阵表示？
✅ 参考答案
  1. 白区边缘窗口会碰到背景，最小值变为 0，边界向内收缩；黑字白底中被扩大的是黑色区域，要按前景极性重新解释。
  2. 宽大于高的矩形核配合闭运算；例如信用卡源码使用宽 9、高 3 的核。应确认它连接组内数字而没有把相邻数字组全部粘连。
  3. 中间值由输入数值的排序决定，参与输出的像素会随输入改变；固定线性权重不会随排序自适应选择像素。
